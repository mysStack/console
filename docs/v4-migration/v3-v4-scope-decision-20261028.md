# V3→V4 范围决策：全量迁移 vs 只迁移影响使用的部分（2026-10-28）

> 基线：`release-4.1.5` @ `8954c6595`（已包含 V3 桥接修复）。
> 本文用 REA 逆向取证作为辅助，**不做代码改动**；结论只决定“迁移范围”，不代替业务取舍。

## 1. 要回答的问题

| 选项 | 含义 |
| --- | --- |
| **A 全量迁移** | 把 138 个 V3 嵌入页面全部改写成 V4 原生实现，最终移除 `consolev3` |
| **B 影响使用的部分** | 只改写“业务必须改、且宿主桥接解决不了”的页面，其余保持 V3 嵌入 |

## 2. 判据：能做 ≠ 需要做

两个维度必须分开，不能用一个维度决定：

- **能做**（技术可行性）：修复点能否只落在宿主桥接层（`ConsoleV3ResourceList`、`useV3Actions`、Wujie 封装），不改 V3 内部。
- **需要做**（业务必要性）：该页面在生产的使用频率 × 出错后果，由业务方填写，工程侧不代填。

| | 需要做 | 不需要做 |
| --- | --- | --- |
| **能做** | 修桥接层，成本最低 | 保持现状 |
| **不能做**（必须改 V3 内部） | **定向 V4 重写 ← 这才是迁移范围** | 不处理，记录风险 |
| **未知** | 先验证再定级 | 暂不投入 |

## 5. 两个选项对比

> 成本为**粗估**，需在范围确定后重估；不作为承诺。

| 维度 | A 全量迁移 | B 影响使用 |
| --- | --- | --- |
| 范围 | 138 个页面全部重写 | 仅“需要做 ∩ 不能做” |
| 粗估工作量 | 100+ 页面 × 2–5 人天 | 预计 10–30 人天（取决于交集大小） |
| 主要风险 | 行为差异、字段/权限对齐、测试矩阵爆炸、并行开发冲突 | 桥接层依赖 wujie 私有字段；V3 行为仍是黑盒 |
| 收益 | 彻底移除 V3，长期可控 | 快速稳定，成本低；V3 债务保留 |
| 前提 | 需要完整 REA + 逐页验收 | 需要可靠盘点 + 业务分级 |

## 6. 非 admin 冒烟结果（2026-10-28，新证据）

测试账号：`platform-regular` + `dev-workspace-regular` + `dev-wms viewer`（用后已删除）。

| 场景 | 结果 |
| --- | --- |
| 有权限项目 `dev-wms` 容器组 | 8 行正常渲染，4152 ms |
| 无权限项目 `dev-biz` 容器组 | **0 行，无数据泄露**；KAPI 拒绝；内容区空白无提示 |
| 集群级 `/clusters/host/pods` | 跳转 `/errors/403` |
| 基线镜像 `fc1253c` 同场景 | **同样空白无提示** → 既有行为，非本次桥接改动引入 |

补充：`dev-workspace-viewer` 的规则为 `['*']/['*']/get,list,watch`，按 KubeSphere 语义可读工作空间内所有项目资源；
做“最小权限”验证时应用 `dev-workspace-regular` + 目标项目 `viewer`，否则会误判为越权。

| 项目容器组详情 | `…/projects/dev-wms/pods/<pod>` | 属性、资源状态、容器、存储区块完整；日志/终端入口未点击验证 | 能做；交互项待补 |

| 工作空间概览 | `/workspaces/dev-workspace/overview` → `…/usage` | 同上，V4 原生 | 不在迁移范围 |

测量说明与偏差：

- 这些页面的内容不在 `shadowRoot.innerText` 中（返回 0），早期用文本长度判定会误报“空白”；本次改用元素计数 + 截图复核。**后续自动化验收不要再用 innerText 判定 V3 嵌入页是否渲染。**
- 一次容器组详情显示 `NotFound`，原因是选中的 CronJob Pod 已被回收，属数据问题，不是页面缺陷；换用 Deployment 的常驻 Pod 后渲染正常。
- 结论只覆盖上表页面；盘点表里其余约 30 个“未知”页（各资源详情、集群设置、联邦项目等）仍未逐页验证，`需要做` 列也仍待业务填写。

## 7. 建议

**选 B**，但需要三个前置条件：

1. 业务填完“需要做”（A 高频核心 / B 偶尔 / C 基本不用）。
2. 工程验证 39 个“未知”页的“能做/不能做”，优先终端、日志、监控、概览。
3. 交叉得到重写清单，按页面验收，不再按模块整批迁移。

**不建议现在选 A**：138 个页面里已有 99 个被证明可由宿主桥接覆盖，全量重写会把已解决的问题重新做一遍，
并引入新的行为差异风险；且 V3 不可重建，重写期间新旧实现需长期并存，成本被低估。
