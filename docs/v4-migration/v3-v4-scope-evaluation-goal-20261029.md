## 目标定义

回答一个问题，并给出可执行结论：

**V3→V4 是“全量迁移 138 个嵌入页”，还是“只迁移影响使用、且宿主桥接解决不了的部分”？**

验收标准（全部满足才算完成）：

1. 138 个嵌入点全部有“能做 / 不能做”结论，不留“未知”。
2. “需要做”由业务填写完成（A 高频核心 / B 偶尔 / C 基本不用），工程不代填。
3. 交集（需要做 ∩ 不能做）形成定向重写清单，含页面、路由、工作量级。
4. A/B 两选项的成本、风险、前置条件有量化对比，可进入决策会。
5. 所有“能做”结论都有部署后浏览器证据，不用本地构建代替。
