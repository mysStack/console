## 证据使用规则

- 当前制品、旧源码、V4 实现和浏览器结果分别记录；静态推断不能写成运行时验证。
- V3 证据必须有 Bundle SHA/位置或派生模块与原 Bundle 的偏移映射、Action 名称/参数、浏览器制品身份及请求记录。只有 `EDIT_SETTINGS` 字符串或 REA Evidence ID 不足以证明表单完整。
- 现有 V4 的“原样保留”与“可查看/可编辑/可校验”分别判定；无字段损失不能证明编辑等价。
- 每个确认的 V3 字段展开为一条字段记录：JSON 路径、UI 分区、默认值、显示条件、输入转换、校验、写入/清空/保留语义、权限、V4 对应、正反测试和证据引用。未知不填成“不适用”。
